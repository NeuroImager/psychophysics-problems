# Psychophysics Assessment Portfolios

A collection of psychophysics problems and scenarios designed for educational assessment and learning. This repository contains two complete assessment portfolios, each with ten structured scenarios covering various aspects of classical psychophysics.

## Overview

This project provides a complete set of psychophysics assessment materials covering real-world applications in healthcare, marketing, technology, and research. In total there are 20 complete scenarios for students to work through, testing knowledge of classical psychophysical principles, including:

- **Thresholds** (absolute and difference)
- **Psychophysical methods** (Constant Stimuli, Limits, Adjustment, AFC)
- **Perceptual scaling** (Weber's and Fechner's Laws)
- **Data interpretation and visualization**

## Usage

- Click: https://NeuroImager.github.io/psychophysics-problems/
- Navigate through the scenarios using the left sidebar
- Each scenario includes background information, data tables, and questions
- Questions for you to answer are presented in italics
