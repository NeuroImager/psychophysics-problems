# Psychophysics Assessment Portfolios

Welcome! This site contains a collection of psychophysics problems and scenarios designed for educational assessment and learning. If you're teaching or learning about psychophysics and perception, then these problems should help reinforce some of the concepts.

There are two complete set of psychophysics assessment materials covering real-world applications in healthcare, marketing, technology, and research. In total there are 20 complete scenarios for you to work through, testing knowledge of classical psychophysical principles, including:

- Thresholds (absolute and difference)
- Psychophysical methods (e.g. Constant Stimuli, Limits, Adjustment)
- Perceptual scaling (e.g. Weber’s and Fechner’s Laws)
- Data interpretation and visualisation

Each scenario includes a description, example data, and questions.
